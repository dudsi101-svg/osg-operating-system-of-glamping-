## P0 proof rule

A scenario seed proving that valid data can be represented is not the same as a concurrency/invariant proof.

Schema v1.0 FINAL still requires the suites defined in:
- `../tests/specs/OSG_P0_Proof_Execution_Plan_v0.1.md`
- GitHub Issues #1–#5

## Runtime roles / RLS

RLS must be tested using a realistic application DB role. PostgreSQL table owners/superusers may bypass RLS. Do not declare tenant-isolation proof successful when tests run only as owner/superuser.

## IDs

Canonical business entity IDs are UUIDv7 generated by the application/shared ID layer (ADR-007). Deterministic fixture IDs in seeds are only test/reference IDs.
