# Dokumentacja OSG

Ten katalog jest kanonicznym miejscem dla dokumentacji domeny, decyzji i definicji OSG.

## Struktura

- checkpoints — zamknięte podsumowania kolejnych etapów,
- decisions — Architecture Decision Records,
- data-model — encje, relacje, kardynalności i integralność,
- business-rules — reguły domenowe i state machines,
- metrics — definicje KPI, formuły i wymagania jakości danych.

## Aktualny punkt odniesienia

- ADR-001: PostgreSQL jako główna baza danych OSG

## Zasada pracy

Najpierw utrwalamy znaczenie biznesowe, relacje, reguły i decyzje. Kod aplikacji rozpocznie się dopiero po akceptacji fundamentów.
